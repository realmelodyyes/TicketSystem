# 世界杯门票销售系统
基于 C++ 与数据结构实现的世界杯门票模拟销售系统，采用队列完成排队购票、窗口售票、自动模拟、数据统计与查询等完整业务流程。

## 项目简介
本系统模拟世界杯门票线下销售场景，通过**队列**实现购票者排队管理，支持手动初始化、窗口售票、自动模拟、数据导出统计、票号查询等功能，界面为控制台交互模式，操作简洁直观。

## 功能模块
- 初始化排队：手动设置购票人数，生成购票队列
- 窗口购票：人工窗口处理队列用户购票
- 自动模拟：系统自动完成排队、售票全流程模拟
- 导出统计：将售票数据导出并进行统计
- 售出号码：查看已售出门票的票号信息
- 信息查询：按条件查询门票销售状态
- 退出系统：安全退出程序

## 运行说明
1. 启动程序后，控制台显示主菜单
2. 队伍为空时，需先选择**功能1 初始化排队**
3. 按提示输入购票人数（范围：1-300）
4. 依次使用窗口购票、自动模拟、统计、查询等功能
5. 输入 0 退出系统

## 运行环境
- 操作系统：Windows 10/11
- 开发工具：Visual Studio 2022
- 开发语言：C++
- 核心数据结构：队列（Queue）

## 系统交互流程
1. 系统启动 → 显示主菜单与提示信息
2. 初始化队列 → 输入人数生成排队序列
3. 窗口售票 / 自动模拟 → 处理购票业务
4. 数据导出统计 → 输出售票结果
5. 售出号码 / 查询 → 查看业务信息
6. 退出系统 → 结束程序运行

## 核心特点
- 基于队列实现排队逻辑，符合真实售票场景
- 控制台友好交互，菜单清晰、操作简单
- 支持人工与自动两种售票模式
- 具备数据统计、导出、查询能力
- 人数限制 1-300，保证系统稳定运行，可根据情况修改
